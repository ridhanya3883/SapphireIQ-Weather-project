# SapphireIQ Weather Project

This is my weather project made with React and Vite. You can search for
a city and it shows the current temperature, humidity and wind speed
using the OpenWeatherMap API.

## Running it

1. Download or clone this repo
2. Run npm install
3. Make a .env file and add VITE_WEATHER_API_KEY=your_key
4. Run npm run dev
5. Open http://localhost:5173

## What I used
- React
- Vite
- OpenWeatherMap API

## Notes
The API key is not uploaded for safety, so you need your own free key
to run it locally.
